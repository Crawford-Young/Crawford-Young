# CLAUDE.md — Crawford-Young profile repo

**Domain:** web — inherits `~/code/CLAUDE.md` (universal) → `~/code/web/CLAUDE.md` (stack + Definition of Done).

GitHub profile README + self-owned stats generator. Every image in the README is a file in `assets/`, generated by code in this repo — zero third-party image services. Workspace standards (`~/code/CLAUDE.md`) apply, **lean scope override**: no Husky, commitlint, coverage gate, Justfile, or Dependabot here.

## Stack

TypeScript ESM (NodeNext, strict, `.js` import extensions) · tsx runner · pnpm 10 (pinned via `packageManager` — corepack's pnpm 11 aborts on this node_modules) · Vitest (snapshot + unit, no coverage gate).

## Commands

| Command | What |
|---|---|
| `pnpm test` | 55 tests: renderer snapshots + heatmap level/layout, language filter, claude window, fmtNum, badge units |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm generate` | Fetch GitHub GraphQL → write `assets/*.svg` + `assets/badges/*.svg` (needs `GITHUB_TOKEN` env — the Action's own token; public data only, any read token works locally) |
| `pnpm export-claude` | Parse `~/.claude/projects/**/*.jsonl` → `data/claude-usage.json` (aggregate daily token counts only — no conversation content) |

## Architecture

- `src/theme.ts` — `palette` = @crawfordyoung/ui dark tokens (component-library `tokens.css` `.dark`), system-ui font stack, `cardFrame` (surface bg, border, radius 8), `fmtNum` (k/M/B, promotes 999_999 → 1.0M), `fmtInt` (1,801)
- `src/calendar.ts` — `layoutHeatmap`: 53 Sunday-start week columns ending on the latest day (missing days zero-filled), month labels (dropped when < 2 columns before the next); `contributionLevels`: quartiles of the non-zero days, busiest day always level 4 — work is bursty (one 200-contribution day, then zeros), so a linear max scale would blank everything else
- `src/github.ts` — one public GraphQL query: default (last-year) `contributionsCollection` → calendar days + `toOverview` (commits = `totalCommitContributions` only — private activity is already in the contributions total); `privacy: PUBLIC` owned non-fork repos → `summarizeLanguages` (pushed in last 365 days, Jupyter/HTML/CSS/SCSS/shell/build files excluded, top 6, GitHub colours kept)
- `src/cards.ts` — heatmap (760 full width) / overview + languages (375 each, side by side) / claude (760) renderers
- `src/badges.ts` — flat-square badges in brand colour (`textColorFor` picks black/white), simple-icons paths vendored at build; hand path for LinkedIn, text-only for Playwright + GDScript (absent from simple-icons v15 and v16)
- `src/claude.ts` — JSONL dedupe by message id, bucket by local date, invalid timestamps skipped BEFORE marking id seen; `toClaudeDays` = 30 days ending on `claudeWindowEnd` (the UTC day before generation — the 06:00 UTC Action runs before that day's 18:00 local export), zero-filled — stale data shows as zeros, never a shifted window
- `src/generate.ts` — Action entry; claude.svg renders only if `data/claude-usage.json` exists
- `src/export-claude.ts` + `scripts/export-claude.ps1` — local export (skips unless on a clean `main` apart from `data/`; pull --rebase --autostash → install → export → commit+push if staged diff, one rebase retry)

## Automation

- `.github/workflows/update-stats.yml` — daily 06:00 UTC + manual dispatch; test → generate → commit `assets/` diff as `chore: update stats [skip ci]`. Authenticates with the workflow's own `GITHUB_TOKEN` (no PAT to expire; the old `STATS_TOKEN` secret is unused and can be deleted).
- Windows Scheduled Task `ClaudeUsageExport` — daily 18:00, runs `scripts/export-claude.ps1`. (Re)register with `powershell -ExecutionPolicy Bypass -File scripts/register-export-task.ps1` (idempotent).

## Rules

- README references `./assets/` paths only — never reintroduce external image URLs
- Renderer changes: update snapshots deliberately (`vitest run -u`), verify SVG textually (grep `NaN|Infinity|undefined`, sane width/height) before committing
- `data/claude-usage.json` must contain only `YYYY-MM-DD` keys → `{input, output}` integers — no strings, ever
